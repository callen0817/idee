# Architecture

- TanStack Start, React, TypeScript, Vite and Tailwind v4.
- Public pages live in `src/routes/`; each has distinct `head()` metadata.
- `src/routes/__root.tsx` supplies document metadata, Query context, error boundaries and one router/cache auth transition listener.
- `PublicShell` composes navigation, atmospheric background and footer.
- `src/routes/_authenticated/route.tsx` is the client-only auth gate; `my.tsx` is its account leaf.
- `src/routeTree.gen.ts` is generated by the route plugin. Never author it manually.
- Domain types and content configuration are separate from reusable brand/product/form components.
- The browser Cloud client is generated and uses persisted session storage. Generated integration modules must remain intact.
- `src/start.ts` registers CSRF protection, server error handling and bearer attachment. Internal server business logic should use TanStack `createServerFn`; external webhooks belong in `/api/public/` with caller verification.
- Current build configuration uses the Lovable Vite integration and a Worker-compatible server runtime. The project is not a static GitHub Pages application.
- One application migration exists in `drizzle/migrations/`. Repository changes do not automatically apply migrations.

## Local development

Copy `.env.example` to `.env` privately and populate the same existing public Cloud settings. Run `bun install --frozen-lockfile`, then `bun run dev`. Run `bun test` for export-safety checks. The exported source passed its production build in GitHub CI; select and verify a compatible runtime host before changing URLs.
