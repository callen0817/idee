# IDee

IDee is the Interactive Digital Encounter Engine: an operating system for participating in real life, not a social-media feed.

## Current product

The repository contains a public website and an initial private account shell. Core pages are Home, App, Device, Play, World, Live, For Business, About, Trust, Access, Early Access and Sign In. `/my` requires a verified session.

Concept screens and metrics are illustrative. `DEMO_MODE` identifies demonstrations. The wearable hardware, CPVA, city rollout, social-value progression, discovery, quests and safety mechanisms described by the website are product concepts, not implemented operational capabilities. Do not imply that these capabilities exist in production.

The early-access form is connected to a Cloud table. The account shell currently displays a labelled demo profile rather than a user's earned progress. Authentication offers existing Google and email/password flows; hosted settings and authenticated behavior must be verified before declaring them operational.

## Design

Luminous white, restrained mint, atmospheric glass, generous whitespace and subtle motion. Heat progresses from mint through warmer tones to white-hot. Respect reduced-motion. Independent social-value dimensions must never become one universal score. No infinite feed or pay-to-win.
